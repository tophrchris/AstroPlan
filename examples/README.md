# AstroPlan examples

These are unmodified AstroPlan files exported by AstroGuide and intended for
interop testing.

| File | Coverage |
| --- | --- |
| `seestar-survey.astroplan` | Ordered scheduled survey with notes, offsets, durations, timestamps, and J2000 coordinates. |
| `research-baseline-deep.astroplan` | Deeper five-subject schedule using the portable core. |
| `heart-and-soul-region.astroplan` | Capture Studio framing extension, repeated subject entries, custom panel centers, frame scale, position angle, filters, and equipment context. |

The Heart and Soul example intentionally contains more than one schedule entry
for IC 1805. Those entries represent different framings and must remain
independent when imported.
