# AstroPlan implementation prompts

These prompts are starting points for coding agents implementing AstroPlan in
an existing application. Each prompt points back to the same specification,
schema, examples, and compatibility requirements.

- [Swift](swift.md)
- [Python](python.md)
- [TypeScript](typescript.md)
- [Kotlin](kotlin.md)

Adapt project paths and test commands to the target repository. An
implementation should not claim compatibility until it passes the shared
examples and project-specific round-trip tests.
