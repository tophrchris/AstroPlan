# Security Policy

AstroPlan is a file-format specification and reference implementation kit, not
a hosted service. Security reports are still important when they involve the
validator, skill scripts, schemas, example-processing guidance, or malformed
AstroPlan files that could affect consuming applications.

## Supported versions

The current `main` branch and the latest published draft are supported. Older
draft snapshots may not receive security updates.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather
than opening a public issue. Include:

- the affected file, script, schema, or guidance;
- a minimal reproduction or malformed AstroPlan payload;
- the potential impact on consumers;
- any known mitigations.

Ordinary format questions, interoperability gaps, and non-sensitive parser bugs
can be reported through public GitHub issues.
